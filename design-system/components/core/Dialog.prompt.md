Modal para confirmação ou detalhe de um trecho/documento recuperado.

```jsx
<Dialog open title="Trecho completo" onClose={fn} footer={<Button>Fechar</Button>}>…</Dialog>
```

Scrim teal translúcido com blur de 3px; caixa de raio 20px. Posiciona-se em `position:absolute` para funcionar dentro de telas do UI kit.
