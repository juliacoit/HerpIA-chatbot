Explicação curta de um termo técnico do RAG (score, top_k, groundedness) ao passar o mouse.

```jsx
<Tooltip content="Similaridade semântica entre a pergunta e o trecho."><Badge>score 0,62</Badge></Tooltip>
```

Fundo teal 900, texto branco, raio 8px. Nunca use para texto longo — prefira `hint` do campo.
