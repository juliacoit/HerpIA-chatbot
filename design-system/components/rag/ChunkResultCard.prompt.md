Um item de `resultados` do endpoint de depuração /buscar — mostra o texto do trecho, não uma resposta gerada.

```jsx
<ChunkResultCard score="0,62" fonte="pans" documento="PAN Herpetofauna do Espinhaço" texto="…" paginaInicio={44} />
```

Use na tela de Busca/diagnóstico. O score vem em pílula teal clara; o texto do trecho é literal, nunca resumido.
