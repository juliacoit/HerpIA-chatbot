# Registro de decisões técnicas (ADRs)

Cada arquivo nesta pasta documenta uma decisão técnica ou de processo relevante para o projeto, no formato ADR (Architecture Decision Record).

## Convenção

- Nome do arquivo: `NNNN-titulo-curto-da-decisao.md`, com `NNNN` sequencial e zero-padded (`0001`, `0002`, ...).
- Use o `template.md` como ponto de partida.
- Uma decisão já registrada não deve ser editada para "desfazer" a decisão — se ela mudar, crie um novo ADR e marque o antigo como **Substituída**, referenciando o novo.
